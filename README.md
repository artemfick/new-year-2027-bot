# Бот «До Нового года осталось N дней» — @happy_newyear_2027_bot

## Что и когда приходит
| Когда | Что |
|---|---|
| Каждый день, 00:00 МСК | стикер «До Нового года N дней» (с 100 дней до 1 дня) |
| 31 декабря, 20:00 МСК | стикер «С наступающим Новым годом!» |
| 1 января, 00:00 по Тольятти (23:00 МСК) | «ну че, тольяттинские, с нгшкой чтоли» + стикер «С Новым годом!» |
| 1 января, 00:00 МСК | «московские, с Новым годом 🎄» + стикер «С Новым годом!» |

Тексты и время «С наступающим» меняются вверху `bot.py`.

## Установка (через сайт GitHub)
1. Создай репозиторий на github.com — лучше **публичный** (так GitHub Actions бесплатны без лимита минут; токен всё равно хранится скрыто в Secrets).
2. Add file → Upload files → загрузи `bot.py` и `README.md`.
3. Add file → Create new file → в поле имени напиши `.github/workflows/countdown.yml` и вставь туда содержимое файла `countdown.yml`.
4. Settings → Secrets and variables → Actions:
   - вкладка **Secrets** → New repository secret: `BOT_TOKEN` (токен бота) и `CHAT_IDS` (chat_id группы)
   - вкладка **Variables** → New repository variable: `STICKER_SET` (имя пака)

## Проверка
Сначала проверь на себе: напиши боту в личку `/start`, найди свой id через
`https://api.telegram.org/bot<ТОКЕН>/getUpdates` и временно поставь его в `CHAT_IDS`.
Потом Actions → New Year countdown → Run workflow → выбери режим. Ручной запуск отправляет сразу, без ожидания.
Когда всё ок — замени `CHAT_IDS` на chat_id группы.

## Важно
- GitHub отключает расписание, если в репозитории 60 дней не было изменений. В середине декабря поправь любой файл (например, добавь строчку в README), чтобы до Нового года всё точно сработало.
- Порядок стикеров завязан на пак: №0 = 100 дней … №99 = 1 день, №100 = «С наступающим», №101 = «С Новым годом». Если автор пака что-то в нём поменяет, номера съедут.
